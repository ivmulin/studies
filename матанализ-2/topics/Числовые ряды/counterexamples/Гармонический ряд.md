#counterexample  

Пример расходящегося [[Числовые ряды|ряда]], для которого общий член $\to 0$, то есть не выполняется [[Необходимый признак сходимости числовых рядов|необходимый признак сходимости]].

$$
\sum_{n=1}^\infty \frac{1}{n} = 1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n} + \dots
$$

Для доказательства расходимости воспользуемся [[Критерий Коши сходимости числового ряда|критерием Коши]]:

Достаточно выбрать два члена последовательности частичных сумм $s_n$, расстояние между которым больше конкретного $\epsilon$. Например:
$$
|s_{2n} - s_n| = \frac{1}{n+1} + \frac{1}{n+2} + \dots + \frac{1}{2n} > n \cdot \frac{1}{2n} = \frac{1}{2}.
$$
